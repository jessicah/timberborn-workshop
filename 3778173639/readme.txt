This mod is intended to go in your variant of ~/Documents/Timberborn/Mods.
Timberborn U6 onwards will create these folders for you on 1st boot so look for
them after. Each version of GreedyBuilders is intended to follow the minimum
version of Timberborn it runs on. So if GB's version says 0.6.0.00 like the
1st version that actually follows the TB version almost correctly does then
you can expect the version of TB you need to be at least 0.6.0.00

The *_names.csv files in the Localizations folder were copied directly from
the game assets to fix the "Loki #" issue that some no doubt spotted on the
1st release for the steam workshop. For the non localised stuff you'll have to
create your own variant of the enUS.csv file for that language.
